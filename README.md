# Developer Portal

This nodejs based react web app was created for the purpose of learning the basics of react and how to make functional websites and web apps using node js.

## Stack

This app was built with the following:
- Node JS 20+
- VITE 8.3.4
- react 19.2.8

and a whole lot of other things.

## Testing

The following npm commands should be used for local testing:
```bash
npm ci # or npm install
```
This will install all needed packages

```bash
npm run dev # or npm run build
```
Done. Now you have a functioning copy.
